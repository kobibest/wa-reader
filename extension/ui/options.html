הגדרות WA Reader

התוסף קורא בלבד. כל ההודעות נשמרות בדפדפן הזה, ולא יוצאות ממנו אלא אם תגדיר webhook למטה.

מה לקרוא

שיחות להחרגה
שיחות ברשימה לא נשמרות ולא מיוצאות בכלל (משפחה, רפואי וכו').

סנכרון ושמירה

ייצוא יומי אוטומטי

תיקייה בתוך Downloads
הקובץ נשמר כ-Downloads/<תיקייה>/whatsapp-YYYY-MM-DD.md – מכאן Claude יכול לקרוא אותו לבריף הבוקר.

Webhook (אופציונלי – כבוי כברירת מחדל)

כתובת
כל הודעה חדשה תישלח ב-POST כ-JSON. זה הצעד היחיד שמוציא נתונים מהמחשב.

הפסקת השימוש

מנתק את התוסף מ-WhatsApp Web, מוחק את כל ההודעות השמורות ומבטל את ההסכמה. אפשר להפעיל מחדש בכל רגע.

WA Reader הוא קוד פתוח ולא קשור ל-WhatsApp או ל-Meta. מדיניות פרטיות · GitHub
