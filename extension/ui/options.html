חיבור ל-Claude Desktop

עובד רק עם Claude Desktop (Windows או Mac). לא עובד עם claude.ai בדפדפן או עם האפליקציה בטלפון.

1
מורידים את הקובץ wa-reader.mcpb.
2
ב-Claude Desktop נכנסים ל-Settings ← Desktop app, לוחצים Manage ליד Extensions, ואז Advanced settings ← Install Extension…, בוחרים את הקובץ ולוחצים Install.
3
משאירים את web.whatsapp.com פתוח בכרום ושואלים את Claude בשיחה רגילה (לשונית Chat): "מה מחכה לתשובה ממני בווצאפ?"

שיחות ש-Claude לא יראה

שיחות ברשימה לא נמסרות ל-Claude בשום בקשה.

מנתק את התוסף מ-WhatsApp Web ומ-Claude Desktop ומבטל את ההסכמה. אפשר להפעיל מחדש בכל רגע.
