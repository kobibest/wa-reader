WA Reader – מדיניות פרטיות

בתוקף מ-5 בנובמבר 2026 (גרסה 3) · English below
בקצרה: התוסף מאפשר ל-Claude לקרוא את הודעות ה-WhatsApp Web שלך כשהוא מבקש. כל בקשה ותשובה עוברות מוצפנות דרך שרת ממסר של WA Reader, שמעביר אותן ל-Claude ומיד שוכח אותן. ההודעות לא נשמרות, לא בתוסף ולא בשרת, ואי אפשר לשלוח דרך התוסף הודעות. מי שמעדיף שההודעות לא יעברו בשום שרת יכול להשתמש בחיבור המקומי.

איזה מידע התוסף קורא

  • תוכן הודעות (טקסט וכיתובים), שם השיחה, שם השולח, שעה, וסימונים כמו "קבוצה", "מושתק", "הועבר" ומספר ההודעות שלא נקראו. את המידע הזה Chrome מגדיר כ"תקשורת אישית".
  • מזהה השיחה ב-WhatsApp, שבשיחות פרטיות כולל את מספר הטלפון של איש הקשר, ושמות אנשי הקשר. את המידע הזה Chrome מגדיר כ"פרטים אישיים מזהים".
  • ממדיה (תמונות, קבצים, הודעות קוליות) נקראת רק תווית טקסט, למשל "[image]" או שם הקובץ. הקבצים עצמם לא נקראים.
  • התוסף קורא רק אחרי שאישרת במסך ההפעלה, רק כשכלי AI שחיברת מבקש מידע, ורק כשטאב של web.whatsapp.com פתוח.

לאן המידע עובר

  • חיבור ל-Claude (ברירת המחדל): Claude שולח את הבקשה לשרת הממסר של WA Reader (פונקציה ב-Supabase, ‏wa-mcp). השרת מעביר אותה לתוסף שלך דרך ערוץ Supabase Realtime, התוסף קורא את התשובה מ-WhatsApp Web ומחזיר אותה באותה דרך, והשרת מוסר אותה ל-Claude.
  • בדרך בין השרת לתוסף, הבקשה והתשובה מוצפנות (AES-256-GCM) במפתח שנגזר מהמפתח האישי שלך. Supabase Realtime רואה רק טקסט מוצפן. שרת הממסר מפענח את התשובה בזיכרון רק כדי למסור אותה ל-Claude, ולא כותב אותה לשום מסד נתונים, קובץ או יומן.
  • יומני השרת של Supabase שומרים רק מידע טכני על הבקשה (זמן, סטטוס, כתובת). המפתח האישי שלך נשלח בכותרת (header) ולכן לא מופיע ביומנים, ותוכן ההודעות לא נרשם אף פעם.
  • רק מי שמחזיק במפתח האישי שלך יכול לבקש נתונים, וגם זה רק בזמן ש-WhatsApp Web פתוח אצלך. אפשר ליצור מפתח חדש בהגדרות בכל רגע, והישן מפסיק לעבוד מיד.
  • חיבור מקומי (אופציונלי): אם אתה משתמש בהרחבה ל-Claude לדסקטופ או בשרת MCP מקומי, ההודעות עוברות רק בתוך המחשב שלך (127.0.0.1), ולא בשום שרת.
  • Claude (או כלי AI אחר שחיברת) מעבד את מה שהוא מקבל לפי מדיניות הפרטיות שלו, ושולח את המידע לשרתים של הספק שלו, כמו כל מידע אחר שאתה נותן לו.
  • המפתח לא מעביר מידע לשום צד שלישי אחר, ואין בתוסף או בשרת אנליטיקס או מעקב.

שמירה

  • התוסף לא שומר הודעות. כל בקשה נקראת ישירות מ-WhatsApp Web ונמחקת מהזיכרון אחרי שהיא נמסרת.
  • באחסון המקומי של התוסף נשמרים רק ההגדרות שלך: המפתח האישי, הטוקן המקומי, הפורט, רשימת השיחות המוחרגות, ואם הסכמת.

איך המידע משמש

  • רק כדי לענות לבקשות של כלי ה-AI שחיברת.
  • אין שימוש אחר: לא פרסום, לא מכירה, לא פרופיילינג, לא אימון מודלים על ידי המפתח, ולא דירוג אשראי.

הרשאות

  • web.whatsapp.com: כדי לקרוא את ההודעות.
  • scripting: כדי להתחבר ל-WhatsApp Web רק אחרי שאישרת, ולהתנתק כשאתה מכבה את התוסף.
  • storage: כדי לשמור את ההגדרות.
  • alarms: כדי לחדש את החיבור לשרת הממסר או לשרת המקומי כשהוא נקטע.

שליטה

  • בהגדרות אפשר להחריג שיחות, ואז הן לא נמסרות לכלי AI לעולם. אפשר גם ליצור מפתח חדש, או לכבות את התוסף ולנתק אותו מ-WhatsApp Web ומכלי ה-AI.
  • הסרת התוסף מוחקת את כל ההגדרות שלו, ואחריה שרת הממסר לא יכול להגיע לשום דבר. כדי לנתק את Claude, מוחקים את החיבור WhatsApp ב-Claude (Customize ← Connectors).

Limited Use

השימוש של WA Reader במידע שמתקבל מ-WhatsApp Web ומ-Chrome עומד בדרישות מדיניות הנתונים של Chrome Web Store, כולל דרישות ה-Limited Use.

אין קשר ל-WhatsApp

WA Reader הוא פרויקט עצמאי בקוד פתוח, והוא לא קשור ל-WhatsApp או ל-Meta ולא מאושר על ידן. התוסף משתמש בספרייה הפתוחה WA-JS (Apache 2.0) כדי לקרוא נתונים מתוך WhatsApp Web.

מי עומד מאחורי התוסף

WA Reader פותח על ידי קובי איתן, איתן | דיגיטציה ארגונית (עוסק מורשה, ישראל).

WA Reader – Privacy Policy

Effective November 5, 2026 (version 3)
Short version: WA Reader lets Claude read your WhatsApp Web messages when it asks. Each request and answer travels encrypted through a WA Reader relay server, which hands it to Claude and immediately forgets it. Messages are never stored, neither in the extension nor on the server, and the extension cannot send messages. If you prefer that messages never pass through any server, use the local connection.

Data the extension reads

  • Message content (text and captions), chat name, sender name, time, and flags such as group, muted, forwarded and unread count. Chrome classifies this as "personal communications".
  • The WhatsApp chat ID (which for direct chats contains the contact's phone number) and contact names. Chrome classifies this as "personally identifiable information".
  • For media (images, files, voice notes) only a text label is read, such as "[image]" or the file name. Media files themselves are never read.
  • Reading happens only after you agree on the activation screen, only when an AI tool you connected asks, and only while a web.whatsapp.com tab is open.

Where the data goes

  • Claude connector (default): Claude sends the request to the WA Reader relay (a Supabase Edge Function, wa-mcp). The relay passes it to your extension over a Supabase Realtime channel; the extension reads the answer from WhatsApp Web and returns it the same way; the relay hands it to Claude.
  • Between the relay and the extension, requests and answers are encrypted (AES-256-GCM) with a key derived from your personal key. Supabase Realtime only sees ciphertext. The relay decrypts the answer in memory only to hand it to Claude, and never writes it to any database, file or log.
  • Supabase request logs keep only technical metadata (time, status, URL). Your personal key is sent in a request header, so it is not in those logs, and message content is never logged.
  • Only someone holding your personal key can request data, and only while your WhatsApp Web is open. You can create a new key in settings at any time; the old one stops working immediately.
  • Local connection (optional): with the Claude Desktop extension or a local MCP server, messages travel only inside your computer (127.0.0.1) and never through any server.
  • Claude (or another AI tool you connect) processes what it receives under its own privacy policy and sends it to its provider's servers, like anything else you give it.
  • The developer does not pass data to any other third party. There is no analytics or tracking in the extension or the relay.

Storage

  • The extension does not store messages. Each request is read live from WhatsApp Web and released from memory once delivered.
  • Only your settings are kept in the extension's local storage: your personal key, the local token, the port, the excluded-chats list, and your consent.

How it is used

  • Only to answer requests from the AI tools you connected.
  • No other use: no advertising, selling, profiling, model training by the developer, or creditworthiness assessment.

Permissions

  • web.whatsapp.com: to read your messages.
  • scripting: to attach to WhatsApp Web only after you consent, and to detach when you turn the extension off.
  • storage: to keep your settings.
  • alarms: to re-establish the connection to the relay or the local server when it drops.

Your control

  • In settings you can exclude chats (never returned to any AI tool), create a new key, or turn the extension off, which detaches it from WhatsApp Web and from AI tools.
  • Uninstalling removes all of its settings, after which the relay cannot reach anything. To disconnect Claude, remove the WhatsApp connector in Claude (Customize → Connectors).

Limited Use

The use of information received from WhatsApp Web and Chrome by WA Reader complies with the Chrome Web Store User Data Policy, including the Limited Use requirements.

WA Reader is an independent open-source project. It is not affiliated with, endorsed by or sponsored by WhatsApp or Meta. It uses the open-source WA-JS library (Apache 2.0) to read data inside WhatsApp Web.
